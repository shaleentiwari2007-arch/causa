#  CAUSA

> Everything has a cause.

CAUSA is an AI-powered knowledge exploration platform that transforms static information into an interactive universe of connected ideas.

##  Features

- Interactive Knowledge Graph
- AI-powered Exploration
- Beautiful Space-inspired UI
- Responsive Design
- Modern Animations

##  Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Framer Motion
- Git
- GitHub
